# Jarvis Assistant

A local, voice-controlled AI assistant inspired by Iron Man's J.A.R.V.I.S. It listens for a wake word, understands your voice,
thinks with a local language model, controls your Windows PC and answers out loud, in **French, English and Turkish** (can be changed).


## Features

- **Wake word**: say "Hey Jarvis" to start a command (openWakeWord)
- **Offline speech recognition** with automatic language detection (faster-whisper)
- **Local brain**: replies and decisions generated by a model running in Ollama
- **Offline voice** with an adjustable "Jarvis" audio effect (Piper + pedalboard)
- **PC control**: screen brightness, volume, launch and close applications, restart and shut down
- **Text mode** if you prefer typing

## Requirements

- Windows 10 or 11
- Python 3.12
- [Ollama](https://ollama.com) installed, with the model used by the project:
```
  ollama pull qwen2.5:7b
```
- A microphone and speakers (a headset avoids Jarvis hearing himself)
- Internet is needed **once**, at the first launch, to download the models. After that, everything runs offline.

## Installation

```
git clone https://github.com/YOUR_USERNAME/jarvis.git
cd jarvis
pip install -r requirements.txt
```

### Files you must provide yourself

Some files are not in this repository (see `.gitignore`), because they are personal or protected by their own licenses.

**1. Your applications list**

Copy `src/app_paths.example.py` to `src/app_paths.py` and edit it. Each entry has three items: the path (or a `steam://` link),
the process name used to close it (or `None` to forbid closing), and a list of aliases.

```python
applications = {
    "steam": (r"C:\Program Files (x86)\Steam\steam.exe", "steam.exe", []),
    "vscode": (r"C:\Users\YOUR_NAME\AppData\Local\Programs\Microsoft VS Code\Code.exe", "Code.exe", ["visual studio code", "code"]),
}
```

**2. Piper voices**

Create a `piper_voices` folder and put one voice per language inside it. Each voice is two files: a `.onnx` and a `.onnx.json`. You can download them from the [Piper voices page](https://huggingface.co/rhasspy/piper-voices), or with:

```
python -m piper.download_voices <voice_name>
```

Then set the names in `VOICES` at the top of `src/voice_piper.py`.

> **Check the license of each voice** before using or sharing it. No voice model and no audio from the films is included in this project.

## Usage

Or double-click `jarvis.bat`, or run:

```
python src/main.py
```

1. Wait for the `[Ears] Ready.` message.
2. Say **"Hey Jarvis"** and wait for the beep.
3. Speak your command. The recording stops by itself when you stop talking.

To close Jarvis, say "quit" or press `Ctrl+C`. For text mode, set `VOICE_MODE = False` in `src/main.py`.

## Configuration

| What | Where | Setting |
|---|---|---|
| Voices and effect (echo, chorus, filters) | `src/voice_piper.py` | `VOICES`, `EFFECTS_ENABLED`, `CHORUS_MIX`, `REVERB_WET` |
| Wake word sensitivity | `src/ears.py` | `WAKE_THRESHOLD` |
| Speech recognition model and speed | `src/ears.py` | `WHISPER_MODEL`, `WHISPER_DEVICE` |
| Microphone sensitivity | `src/ears.py` | `VOICE_THRESHOLD`, `SILENCE_SECONDS` |
| Language model and personality | `src/functions.py` | model name, `SYSTEM_PROMPT` |

## Project structure


jarvis/
├── jarvis.bat            # launcher
├── requirements.txt
└── src/
    ├── main.py           # main loop
    ├── functions.py      # AI logic: prompt, Ollama, action dispatch
    ├── action.py         # what Jarvis can do on the PC
    ├── ears.py           # wake word, recording, speech recognition
    ├── voice_piper.py    # speech synthesis and effects
    └── app_paths.py      # your applications (not in the repository)


## Security

- The AI **never gives a command or a path**, only the name of an application. It must exist in your `app_paths.py` list (name or alias) for anything to run.
- Closing an application is only possible if you gave it a process name.
- Restarting and shutting down ask for a confirmation.
- Do **not** run Jarvis as administrator: nothing in the project needs it.

## Known limitations

- Windows only (volume, brightness and process control use Windows tools).
- Restart and shutdown confirmations still need the keyboard.
- The wake word is "Hey Jarvis" (pre-trained model), not "Jarvis" alone.
- Speech recognition runs on the CPU by default, so expect a short delay after each command.
